description=[h1]Multiplayer Carry Weight: Feather Weight System[/h1]
description=[b]In Multiplayer (Dedicated and Co-op)[/b], bag weight capacity is enforced server-side by the Java engine and can't be bypassed directly — but it CAN be worked around cleanly. This update adds an optional [b]Item Weight Multiplier[/b] sandbox setting that scales down item weights so grid space, not weight, becomes what actually limits what you can carry. A fridge still weighs more than a nail relative to everything else, so encumbrance still means something, but you're no longer capped by the Java server's hard weight ceiling before your grid slots run out. Set to 1.0 (default) to leave vanilla weight behavior fully untouched. Grid sizing/stack counts are unaffected by the multiplier at any value — items keep their original footprint regardless of how weight is scaled.
description=

description=[h2]1. Core B42 Fixes[/h2]
description=[list]
description=[*][b]Tick Errors (isNPC/AnimalContextMenu):[/b] Replaced legacy NPC context handlers with B42 entity guards.
description=[*][b]Drag-and-Drop & Transfers:[/b] Hooked into B42's server-authoritative ItemTransactionPacket flow for accurate grid placement.
description=[*][b]Singleplayer Container Weight Limit Fixed:[/b] During capacity checks, temporarily disguises the target container as a "floor" container (vanilla-exempt from weight limits), runs the check, then reverts it immediately after — so SP containers hold what fits in the grid instead of capping at 50kg/100kg. Skipped for the player's main inventory, fragile containers, and automatically no-ops in Multiplayer.

description=[h2]5. Multiplayer Carry Weight (Feather Weight)[/h2]
description=The item-weight-scaling architecture used to solve the MP carry-weight limitation (Feather Weight system) is the the approach pioneered by [b]@Valah[/b]'s fork of Inventory Tetris. Thank you for this.
description=[list]
description=[*][b]Item Weight Multiplier:[/b] New shared-side system (TetrisMPConfig) that scales script item and moveable/furniture weights so grid space becomes the real carrying limit in MP. Off by default (1.0).
description=[*][b]Grid Sizing Preserved:[/b] Inventory Tetris sizes items from their ORIGINAL unscaled weight regardless of multiplier, so footprints and stack sizes never shift when the setting changes.
description=[*][b]Late-Built Item Repair:[/b] Fixes the "multiplier worked randomly" issue where items deserialized before the sandbox value loaded (own inventory, already-loaded chunks) kept vanilla weight forever.
