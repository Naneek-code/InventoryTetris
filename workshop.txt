title=Inventory Tetris - Grid Based Items and Equipment Overhaul
description=Inventory Tetris completely replaces Project Zomboid’s normal list-based inventory with a grid system where items actually take up space. Bigger items need more room, things can be rotated to fit, and organizing your bags becomes part of the game instead of just sorting a list.
description=
description=This version is being actively maintained for Build 42.20 with a pretty heavy focus on Singleplayer, Multiplayer, Dedicated Servers, persistence, compatibility, and fixing the weird edge cases that come from changing such a core part of the game.
description=
description=Equipment UI is also included directly with Inventory Tetris now, so you do not need to install the old discontinued version separately. The goal is to keep everything feeling like one cohesive inventory system while staying as compatible with vanilla Project Zomboid as we reasonably can.

description=[h1]FEATURES[/h1]
description=[h3]Grid-Based Inventory[/h3]
description=Every item has a physical size and has to actually fit inside the container you’re putting it in. You can move things around, rotate them, stack compatible items, and organize your inventory however makes sense to you. Different bags and containers have different layouts, so what you carry and how you pack it actually matters.
description=[h3]Containers, Pockets & Equipment[/h3]
description=Inventory Tetris goes a lot deeper than just replacing the main inventory window. Backpacks, nested containers, pockets, worn equipment, and the Equipment UI all work together as part of the same system. Moving something from your backpack to a pocket or onto your character should still feel like one connected inventory rather than a bunch of unrelated menus.
description=[h3]Vanilla Trait Integration[/h3]
description=Inventory traits have been adapted to work with the grid system. [b]Organized[/b] and [b]Disorganized[/b] affect container capacity when weight limits are enforced, while Disorganized also makes automatically placed items less neatly packed. With Search & Discovery enabled, [b]Dextrous[/b] searches containers faster and [b]All Thumbs[/b] searches them slower.
description=[h3]Search & Discovery (Optional)[/h3]
description=You don’t always have to immediately know what is inside a container. With Search & Discovery enabled, containers have to be searched before their contents are fully revealed. It makes looting a little slower and more deliberate, and gives searching through houses, vehicles, bodies, and storage areas a lot more personality.
description=
description=You can enable it in the Sandbox Options under [b]Inventory Tetris: Search[/b]. Turn on [b]Enable Search Mode[/b] there.
description=[/quote]
description=
description=[quote]
description=[h1]SETTINGS[/h1]
description=Inventory Tetris has quite a few ways to customize how the system plays. Here are some of the settings that make the biggest difference.
description=[h3]Global Bonus Grid Size[/h3]
description=Add extra width and height to all Inventory Tetris container grids. The default is [b]0[/b], with up to [b]8[/b] additional grid spaces available globally.
description=[h3]Item Weight Multiplier[/h3]
description=Adjust the actual weight of items without changing how much physical grid space they occupy. [b]1.0[/b] keeps normal item weights, while lower values make items lighter.
description=[h3]Grid Scale[/h3]
description=Adjust the size of the Tetris inventory grid to better fit your resolution, UI scale, and personal preference.
description=[h3]Global Stack Size Multiplier[/h3]
description=Increase or decrease Inventory Tetris stack limits globally. [b]1.0[/b] is the default. Values below 1.0 reduce stack sizes, while values above 1.0 increase them. Items that are not already stackable remain non-stackable. The multiplier can be set from [b]0.01 to 100.0[/b].
description=[h3]Enable Search Mode[/h3]
description=Hide the contents of eligible containers until your character searches through them. [b]Search Time[/b] controls how quickly items are revealed, while [b]Corpse Search[/b] can be set to Disabled, Some Items, or Enabled.
description=[h3]Use Item Transfer Time[/h3]
description=Enable calculated transfer times when moving items between containers.
description=
description=This setting is [b]Singleplayer only[/b].
description=[h3]Item Transfer Speed Multiplier[/h3]
description=Adjust how quickly timed item transfers are completed in Singleplayer.
description=
description=This setting is [b]Singleplayer only[/b].
description=[h3]Enforce Carry Weight[/h3]
description=Enforce vanilla container capacity limits alongside the Tetris grid. 
description=
description=In Multiplayer, these capacity checks are enforced for server authority. We cannot override this behavior because Project Zomboid enforces it!
description=[h3]Encumbrance Slowdown[/h3]
description=Slow your character when carrying a very heavy load, allowing weight to remain an important part of inventory management even with the grid system.
description=[h3]...and Quite a Few More![/h3]
description=Additional settings are available for controls, UI scaling, visual options, container stacking rules, and other fine tuning.

description=[h1]FAQ[/h1]
description=[h3]Does Inventory Tetris work in Multiplayer?[/h3]
description=[b]Yes.[/b] This version supports Singleplayer, hosted Multiplayer, and Dedicated Servers. Multiplayer and persistence are areas we continue to actively test, so if you find something strange on a server we definitely want to hear about it.
description=[h3]Do I need another version of Inventory Tetris installed?[/h3]
description=[b]No.[/b] This Workshop item contains Inventory Tetris itself. You should not load multiple versions of Inventory Tetris at the same time.
description=[h3]Do I need Equipment UI installed separately?[/h3]
description=[b]No.[/b] Equipment UI is now included directly with Inventory Tetris.
description=
description=[b]If you still have the old standalone Equipment UI installed or enabled, please disable or unsubscribe from it.[/b]
description=[h3]Can I use this on an existing save?[/h3]
description=The current version is designed to preserve Inventory Tetris’s existing persistence data. That said, this is Project Zomboid and Inventory Tetris changes a pretty fundamental part of the inventory system. Backing up an important save before any major mod update is always a good idea.
description=[h3]Can I remove Inventory Tetris from an existing save?[/h3]
description=We do not recommend treating Inventory Tetris as a mod that can be freely added and removed from an active save. It changes inventory behavior and stores additional information about container layouts and items. If the save matters to you, make a backup before changing your mod list.
description=[h3]How do key rings work?[/h3]
description=Key rings are treated differently from normal Tetris containers. The key ring itself still takes up space in your inventory, but the keys stored inside it do not need individual Tetris grid positions. You can open the ring and move keys in and out normally, including dropping keys directly onto it.
description=[h3]Why can’t I move items in my inventory?[/h3]
description=If items can’t be moved to/from containers, or simple inventory actions are freezing in place, you are almost certainly experiencing an incompatibility issue with another mod that changes Project Zomboid’s vanilla interface behavior.
description=[h3]Is this compatible with other inventory mods?[/h3]
description=Inventory Tetris replaces a large part of Project Zomboid’s inventory interface and behavior, so mods that replace or heavily modify the same systems may conflict. We try to preserve vanilla behavior and compatibility wherever practical, but we cannot guarantee compatibility with every inventory, equipment, or container overhaul.
